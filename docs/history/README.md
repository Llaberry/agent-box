## ⭐ Claims this project has published and later withdrawn

**None yet.** This project has published one session's work.

⚠ **An empty list is not a good sign.** It means nothing has been checked a
second time, not that everything is right. The first entry here will be a
correction to something in [`references/`](references/), and
[`references/README.md`](references/README.md) already says which five claims
are most likely to be it.

⛔ **A reader who trusts a document without checking this list trusts sentences
that may be wrong.** When a claim is withdrawn it gets a row here, with what was
believed, what was measured, and the date.

| date | the claim | what took it away |

| 2026-09-15 | **The agent harness was pinned as `earendil-works/pi`.** Eighteen quotations were cited to it. | The operator named `earendil-works/pi` as the canonical repository. ⭐ **Every quotation is still verbatim correct**: both clones resolve to commit `f9bcd351dc3cedf989bc5fc0f8aa012db5737df2` and the five cited files are byte-identical. ⛔ **What was wrong was the provenance, not the claim.** A citation naming a repository nobody goes to is uncheckable where people actually look, so the pin now names the canonical one. |

## The rules on this directory

- ⛔ **Append, never edit.** A premise a later measurement disproves keeps its
  wording, and the correction goes underneath it.
- ⛔ **Moved, not summarised.** A superseded passage arrives here in its
  original words.
- ⚠ **One fact one home does not apply here**, on purpose: a superseded page
  states things the live pages now state differently. Everything else in
  [`../conventions/prose.md`](../conventions/prose.md) does apply, including the
  character set and the marker density.
