## The rules on this directory

- ⛔ **Append, never edit.** A premise a later measurement disproves keeps its
  wording, and the correction goes underneath it.
- ⛔ **Moved, not summarised.** A superseded passage arrives here in its
  original words.
- ⚠ **One fact one home does not apply here**, on purpose: a superseded page
  states things the live pages now state differently. Everything else in
  [`../conventions/prose.md`](../conventions/prose.md) does apply, including the
  character set and the marker density.
